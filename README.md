# 💻 C/C++ & DSA — Learning Journey

This repository will document my journey of learning **C/C++ programming** and **Data Structures & Algorithms (DSA)** from the ground up.  

I will be adding notes, exercises, code snippets, and mini projects as I progress, covering everything from the basics to advanced problem-solving techniques.

---

## 📌 What I Will Be Learning

### **C/C++ Programming**
- Basics: Variables, Data Types, Operators, Input/Output  
- Control Structures: `if-else`, `switch`, Loops (`for`, `while`, `do-while`)  
- Functions and Recursion  
- Arrays, Strings, and Pointers  
- Structures, Classes, and Object-Oriented Programming (C++)  
- File Handling and Error Management  

### **Data Structures & Algorithms**
- **Linear Data Structures**: Arrays, Linked Lists, Stacks, Queues  
- **Non-linear Data Structures**: Trees (Binary, BST), Graphs, Heaps  
- **Algorithms**: Searching (Linear, Binary), Sorting (Bubble, Selection, Insertion, Merge, Quick)  
- Recursion & Backtracking  
- Dynamic Programming  
- Graph Algorithms: BFS, DFS, Dijkstra, etc.
